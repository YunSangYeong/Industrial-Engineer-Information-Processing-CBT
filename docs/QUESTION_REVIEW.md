# 문제은행 제작·검수 기록

## 실제 수량

기본 JSON: `src/data/questions.json`. 생성 원고·조건: `scripts/generate_bank.py`. 자료 ID `main`은 내부 자료 식별자이며 출제 연도가 아니다.

| 과목 | 개념형 | 숫자 조건 변형 | 변형 family | 합계 |
| --- | ---: | ---: | ---: | ---: |
| 정보시스템 기반 기술 | 20 | 336 | 14 | 356 |
| 프로그래밍언어 활용 | 20 | 305 | 13 | 325 |
| 데이터베이스 활용 | 20 | 299 | 13 | 319 |
| 합계 | 60 | 940 | 40 | 1,000 |

원문 기출 0 / 복원 0 / 자체 제작 1,000. 내부 검수 완료 등록 1,000, 검증 대기 0, 제외 0, 목표 대비 부족 0. 개인 로컬 등록분은 이 수에 포함하지 않는다. 이는 **1,000개의 독립 개념이나 기출을 뜻하지 않는다**. 개념형 60개와 계산·코드 추적 40유형을 합쳐 학습 유형은 100개이며 숫자 조건 변형 비중이 94%다. 실제 시험의 내용·난이도·출제 비중을 입증하는 은행은 아니다.

## 제작과 내부 검수 범위

- 60개 개념형에 대해 정답과 세 오답의 의미, 해설 문장, 한 개 정답 여부를 내부 대조했다.
- 40개 계산·코드 추적 템플릿에 대해 문제 조건과 해설 식을 검토했다. 단위, 오버헤드 제외, Python의 정수·인덱스·range 의미, SQL NULL·중복·행 수 조건 등을 명시했다.
- Python 생성 경로와 별개인 TypeScript/JavaScript 경로로 **940개 전부**를 재계산한다. 반복·배열·집합·정수 연산을 이용하고 생성 함수를 불러오지 않는다. 정답 번호, 유일한 수치 보기, 정수 안전 범위, 해설의 결과 표기를 함께 검사한다. 모든 계산은 정수로 반올림이 없다.
- `reviewed`는 이 내부 검토와 자동 검사를 뜻한다. 같은 AI 작업의 개념·문장 검토이며 **독립된 사람 또는 외부 전문가 검수는 아니다**. 자동 계산 검사만으로 해설 전체의 외부 검증을 주장하지 않는다.
- 공식 원문 접근이 차단되어 현행 출제기준의 단원별 대조와 공식 규정 검증은 미완료다. 자체 자료 이용 조건을 표시했으며 원문 기출의 권리를 확보했다는 뜻이 아니다.

## 중복과 변형

모든 ID와 NFKC·공백 정규화 본문/정렬 보기 fingerprint가 고유함을 검사한다. ID 중복과 보기 순서만 다른 동일 문항은 가져오기에서도 제거한다. 템플릿을 비교하여 서로 다른 조건을 쓰는 변형은 family로 묶었다. 비트 수와 주소선 수처럼 같은 공식을 다른 문맥에서 쓰는 유사 유형이 있으며 의미 중복을 외부 전문가가 전수 판정한 것은 아니다. 단순 문자열 중복 검사 결과를 모든 의미 중복의 부재로 과장하지 않는다.

40 family 중 앞 20개는 각 24조건, 뒤 20개는 각 23조건이다. 합계 940이다. 각 family 내 입력 쌍이 다르고 조건·ID·보기 순서는 결정적이다. 별도의 난수 시드는 사용하지 않는다.

모의시험은 과목별로 family에 우선 한 자리만 배정하고 그 안에서 한 문항을 뽑는다. 각 과목에는 개념형 20개가 따로 있어 기본 은행에서는 같은 숫자 family가 한 시험에 중복되지 않는다. 사용자가 가져온 은행에 독립 family가 부족하면 남은 고유 ID로 보충한다.

## 재현

```sh
python3 scripts/generate_bank.py
npm test
```

두 번 생성한 데이터 SHA-256이 일치함을 확인했다:
`87e92d0709692884013de68c3967026ee91ea86692c009954d1078a0b25c96ac`.

문항의 `year`·`session`은 모두 null. `type`은 모두 original. 원고의 과거 시험 시행일이나 회차를 만들어 넣지 않는다. 입력 양식 예제는 가져오면 검증 대기가 되며 기본 은행 1,000개에 포함하지 않는다.
