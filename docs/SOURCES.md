# 시험 규칙과 출처 확인 상태

대상 명칭은 저장소 README와 요청 문맥에 따라 **정보처리산업기사**로 해석했다. 원본 전기기능사의 시험 규칙과 데이터를 재사용하지 않았다.

## 공식 규칙 확인: 차단, 미완료

조사 대상: 한국산업인력공단 Q-Net 종목 상세
<https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=2290>

2026-11-03 요청 결과: `curl: (56) CONNECT tunnel failed, response 403`, HTTP 응답 코드 `000`. 프록시 단계에서 실패하여 공식 페이지 본문·출제기준 PDF·이용 조건을 읽지 못했다. 이 URL은 조사 대상이며 읽고 검증한 근거가 아니다. 최신 공식 출제기준과 변경 공고 대조는 미완료다.

현재 `src/qualification.ts`는 다음 **학습용 잠정 설정**을 사용한다. AI의 일반 지식에 기초하며 이번 작업에서 공식 검증을 완료한 사실로 표시하지 않는다.

공식 재현 완료를 주장하지 않는다. 현행 규칙·시험시간·과목별 수·채점·과락 및 해당 출제기준의 적용 기간은 실제 응시 전에 공식 공고로 대조해야 한다. 확인 상태는 문제은행 관리 화면에서도 볼 수 있다. 메인·시험 상단 상시 면책 배너는 두지 않는다.

## 문항 출처와 이용 조건

- 원문 기출 **0**, 복원 **0**. 과거 연도·회차·원문 정답·재배포 권리가 확인된 자료를 확보하지 못했다. 연도와 회차는 전부 `null`이다.
- 기본 문항은 AI 일반 지식에서 자체 작성했다. 민간 문제은행, 교재, 공개 기출 원문을 전재하지 않았다. 읽지 않은 공식 문서나 교재를 정답 증빙으로 인용하지 않았다.
- 문항의 `sourceUrl`은 이 프로젝트의 제작·검수 기록 위치다. 독립된 외부 정답 증거가 아니다. 작업 브랜치에만 반영된 동안 main 경로가 아직 존재하지 않을 수 있다.
- 자체 제작 데이터는 CC BY 4.0으로 제공한다. 기여자와 프로젝트 링크를 표시하고 수정 여부를 밝혀야 한다. 외부에서 가져온 개인 자료에는 이 라이선스를 부여하지 않는다.
- 재사용 앱 코드는 원본 MIT 고지를 보존했다. 원본 전기기능사 문항은 포함하지 않았다.
- 검수 범위와 수치 변형 내역은 [QUESTION_REVIEW.md](QUESTION_REVIEW.md)에 기록한다.
